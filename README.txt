ALKAEDAS CONVOY PUERTO RICO — SITIO WEB EN ESPAÑOL

CÓMO ABRIRLO:
1. Extrae el archivo ZIP.
2. Mantén index.html y la carpeta images juntos.
3. Haz doble clic en index.html.

PARA PUBLICARLO EN INTERNET:
Sube index.html y toda la carpeta images a GitHub Pages u otro servicio de alojamiento de sitios estáticos.

GALERÍA:

IMPORTANTE:
No cambies el nombre de la carpeta images ni la separes de index.html.
